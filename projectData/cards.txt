# ==============================================================================
# DOKUMENTACJA STATYSTYK (ŚCIĄGAWKA CO JEST CZYM)
# ==============================================================================
#
# 1. Klasa: Hero (Bohaterowie)
#    Konstruktor: Hero(name, attack, defense, max_hit_points, willpower, sphere_of_influence, threat)
#    - name:                Identyfikator z enum (np. Heroes.Aragorn)
#    - attack:              Siła ataku (miecze) – ile obrażeń zadaje podczas fazy walki.
#    - defense:             Obrona (tarcze) – o ile zmniejsza obrażenia zadawane przez wrogów.
#    - max_hit_points:      Maksymalne punkty życia (HP) – ile ran postać może przyjąć przed śmiercią.
#    - willpower:           Siła woli – statystyka używana do generowania postępu w fazie wyprawy (Quest Phase).
#    - sphere_of_influence: Sfera wpływów (np. Sphere.Spirit) – określa rodzaj generowanych zasobów.
#    - threat:              Koszt zagrożenia – wartość dodawana do poziomu zagrożenia gracza na początku gry.
#
# 2. Klasa: Ally (Sprzymierzeńcy)
#    Konstruktor: Ally(name, attack, defense, max_hit_points, willpower, sphere_of_influence, cost)
#    - name do sphere_of_influence: Działają identycznie jak u bohaterów.
#    - cost:                Koszt w zasobach – ile żetonów danej sfery trzeba zapłacić, aby zagrać kartę z ręki.
#
# 3. Klasa: Enemy (Wrogowie)
#    Konstruktor: Enemy(name, attack, defense, max_hit_points, engagement, threat)
#    - name:                Identyfikator z enum (np. Enemies.Hill_Troll)
#    - attack, defense, max_hit_points: Statystyki bojowe wroga (działają tak samo jak u postaci gracza).
#    - engagement:          Koszt starcia – jeśli poziom zagrożenia gracza jest równy lub wyższy od tej wartości,
#                           wróg automatycznie schodzi ze Staging Area i atakuje gracza w fazie spotkań.
#    - threat:              Zagrożenie wroga – ile punktów zagrożenia wróg dodaje do Staging Area,
#                           utrudniając postęp misji, dopóki nie wejdzie w zwarcie z graczem.
#
# 4. Klasa: Location (Lokacje)
#    Konstruktor: Location(name, threat, required_progress)
#    - name:                Identyfikator z enum (np. Locations.The_East_Bight)
#    - threat:              Zagrożenie lokacji – ile punktów zagrożenia lokacja dodaje do Staging Area.
#    - required_progress:   Wymagany postęp – ile żetonów postępu (progress tokens) należy na niej umieścić,
#                           aby w pełni zbadać i odrzucić tę lokację.
#
# 5. Klasa: Quest (Misje)
#    Konstruktor: Quest(name, scenario, required_progress)
#    - name:                Identyfikator etapu misji z enum (np. Quests.Flies_and_Spiders)
#    - scenario:            Scenariusz, do którego należy misja (np. Scenario.Passage_through_Mirkwood)
#    - required_progress:   Liczba żetonów postępu potrzebna do ukończenia tego etapu wyprawy.
#
# ==============================================================================
